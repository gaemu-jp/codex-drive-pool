プライバシーポリシー

Google ドライブへのアクセス

Codex Drive Pool は Google OAuth の drive.file 権限を使用します。Google Drive API から、専用フォルダー内で本ツールが扱うファイルの内容や、ファイル名・サイズなどの情報を取得します。保存先の選択には、アカウントのストレージ容量と空き容量を利用します。

利用目的と保存先

取得した情報は、Windows の仮想ドライブでファイルを表示、作成、読み取り、更新、削除するために使います。認証トークンとファイルキャッシュは、rclone が利用者の Windows PC に保存します。Google ドライブとの通信は、PC 上の rclone が Google Drive API に直接行います。

この案内サイトは GitHub Pages で配信しています。サイト自体は Google ドライブのファイルや OAuth の認証情報を受け取る機能を持ちません。サイトへのアクセスについては GitHub のプライバシーに関する声明をご覧ください。

アクセスを取り消す

Google アカウントの接続設定を開き、Codex Drive Pool のアクセスを削除できます。クラウド上のファイルは Google ドライブで管理でき、ローカルの認証情報とキャッシュはマウント終了後に Windows PC から削除できます。
